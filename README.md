Desktop Todo

Desktop Todo 是一款面向 Windows 的桌面待办工具，提供待办管理、状态与优先级分类、截止日期、批量导入与导出等功能。

## 下载

请在本仓库的 [Releases](../../releases) 页面下载最新版：

- `Desktop Todo 1.1.0.exe`：免安装便携版，下载后可直接运行。

> Windows 首次运行未知发布者应用时可能显示安全提示。请确认文件来自本仓库的 Release 页面后再运行。

## 主要功能

- 新建、编辑、完成和删除待办事项
- 设置截止日期、状态、优先级和任务说明
- 从 Excel、WPS 或 GPT 生成的表格批量导入任务
- 可配合 Codex 等桌面 Agent，用自然语言生成并添加待办事项
- 导入前预览，自动检查无效日期、未知状态和未知优先级
- 按“任务名称 + 截止日期”识别重复任务并默认跳过
- 将任务导出为 CSV
- 桌面时钟、日历和闹钟
- 支持主题与皮肤

## 系统要求

- Windows 10 或更高版本
- 约 120 MB 可用磁盘空间

## 快速开始

1. 从 Releases 页面下载 `Desktop Todo 1.1.0.exe`。
2. 双击运行应用。
3. 在待办面板中添加任务，或使用“批量导入”粘贴任务表格。

## 批量导入使用说明

### 表格格式

支持从 Excel、WPS 复制的制表符分隔表格（TSV），也支持 CSV。表格必须包含表头和至少一条任务，“任务”列为必需列。

推荐使用以下固定列顺序：

```text
任务	截止日期	状态	优先级	任务内容
```

可识别的表头别名包括：

- 任务：`任务`、`任务名称`、`待办`、`待办事项`、`标题`、`事项`
- 截止日期：`截止日期`、`截止时间`、`到期日期`、`到期时间`、`deadline`
- 状态：`状态`、`任务状态`、`status`
- 优先级：`优先级`、`优先程度`、`星级`、`priority`
- 任务内容：`任务内容`、`任务说明`、`说明`、`备注`、`描述`、`内容`

### 字段规则

#### 任务

- 必填，建议使用简短、明确的“动词 + 对象”名称。
- 不要把日期、状态或优先级重复写进任务名称。
- 同一任务不要生成多个措辞相近的重复项。

#### 截止日期

- 可选，推荐格式为 `YYYY-MM-DD`。
- 应用也可识别 `YYYY/MM/DD`、`YYYY.MM.DD` 和中文年月日格式。
- 日期必须真实存在；无法确定时请留空，不要猜测。
- “今天”“明天”等相对日期应在生成表格前换算为绝对日期。

#### 状态

支持以下标准值：

- `待办`
- `进行中`
- `已完成`

应用也可识别常见别名，例如 `未开始`、`未完成`、`Todo`、`Pending`、`处理中`、`Doing`、`In Progress`、`完成`、`Done` 和 `Completed`。留空时默认为“待办”。

#### 优先级

支持以下标准值：

- `高`
- `中`
- `低`

也可使用英文 `High`、`Medium`、`Normal`、`Low` 或星级：4～5 星映射为“高”，2～3 星映射为“中”，1 星映射为“低”。留空时默认为“中”。

#### 任务内容

- 可选，用于记录材料、金额、地址、联系人、前置条件或完成标准。
- 单元格内不要换行；多个要点可用中文分号 `；` 分隔。
- 不要写入密码、验证码、银行卡完整号码或身份证件号码等敏感信息。

### 标准示例

以下内容使用制表符分隔，可整表复制到 Desktop Todo：

```text
任务	截止日期	状态	优先级	任务内容
预约宿舍	2026-04-21	已完成	高	确认房型、租期和付款方式
提交签证材料	2026-09-09	进行中	高	预约 VFS；核对 CAS、护照和资金证明
完成线上注册	2026-08-20	待办	高	支付学费并确认注册成功
整理抵英行李清单		待办	中	原文未提供具体截止日期
```

### 导入步骤

1. 在 Excel、WPS 或文本工具中准备表格。
2. 复制包含表头的完整表格。
3. 打开 Desktop Todo 的“批量导入待办”。
4. 粘贴内容并点击“解析并预览”。
5. 检查可导入、重复和错误项。
6. 点击“确认导入”。

### 去重与错误处理

- 应用使用“标准化任务名称 + 截止日期”检测重复项。
- 同名且截止日期相同的任务会被视为重复并默认跳过。
- 同名但截止日期不同的任务会被视为不同任务。
- 缺少任务名称、日期无效、状态无法识别或优先级无法识别时，该行不会被导入。
- 不确定的日期应留空；存在冲突信息时，可在“任务内容”中注明候选信息。

## 让 GPT 生成可导入表格

可将下面的提示词发给 GPT，并在末尾粘贴聊天、邮件、文档或会议记录：

```text
请根据我提供的信息提取所有可执行的待办事项，并严格按照 Desktop Todo 批量导入规范输出。

要求：
1. 只输出制表符分隔的 TSV 表格，不使用 Markdown 代码围栏，不添加解释。
2. 固定列顺序为：任务、截止日期、状态、优先级、任务内容。
3. 日期统一为 YYYY-MM-DD；无法确定时留空，不得猜测。
4. 状态只能是待办、进行中、已完成；没有状态时使用待办。
5. 优先级只能是高、中、低；没有依据时使用中。
6. 合并重复任务；同名且截止日期相同的任务只保留一条。
7. 任务名称应简洁、可执行；补充信息放在任务内容中。
8. 不要输出密码、验证码或完整证件号码等敏感信息。

待整理的原始信息如下：
[在这里粘贴原始内容]
```

更完整的规则见 [TODO_IMPORT_RULES.md](TODO_IMPORT_RULES.md)。

## 制作自定义皮肤

Desktop Todo 支持无需修改源码或重新打包的本地扩展皮肤。皮肤可自定义窗口、待办、时钟、闹钟、日历、设置界面和日历贴纸，并可在设置中重新加载。

完整的目录结构、`theme.json`、CSS 作用域、贴纸资源、响应式规则和验收清单见 [皮肤制作规范.md](皮肤制作规范.md)。

## 使用桌面 Agent 自然语言添加待办

Desktop Todo 可以配合 Codex 等能够读取本地规则文件、生成表格或调用本地命令的桌面 Agent 使用。你可以直接用自然语言描述任务，例如：

```text
帮我添加三个待办：
明天下午前提交项目周报，优先级高；
周五预约体检；
月底前整理发票，有空再做。
```

桌面 Agent 应根据当前日期和时区解析相对日期，按照本仓库的 `TODO_IMPORT_RULES.md` 生成 TSV，再通过 Desktop Todo 的批量导入功能添加任务。支持应用集成的 Agent 还可以自动完成导入，无需手动复制粘贴。

推荐向桌面 Agent 发出以下指令：

```text
请读取 TODO_IMPORT_RULES.md，把我接下来描述的事项整理为 Desktop Todo 可导入的待办，并添加到 Desktop Todo。无法确定的日期不要猜测；不要导入密码、验证码或证件号码等敏感信息。
```

使用 Agent 时请注意：

- 明确说明任务、截止时间、状态、优先级和补充信息。
- “明天”“下周五”等相对时间应按本机当前日期和时区转换。
- 无法确认的日期应留空，并在任务内容中记录待确认信息。
- 导入前检查预览页中的重复项和错误项。
- 不要把密码、验证码、银行卡完整号码或身份证件号码交给 Agent 或写入待办。
